# Jev 根先验与 QBAF 的七方法对比实验报告

生成时间：2026-09-26 23:47:22 中国标准时间

## 实验设置

- 论点生成模型：openai/deepseek-v4.1-flash
- 论点生成接口：https://www.dmxapi.cn/v1
- 生成模型思考模式：disabled
- Jev 请求模型：jev-latest
- Jev 实际响应版本：jev-1.13.0
- 本次运行方式：仅读取既有响应缓存，不发起 API 请求。
- 数据：上游仓库三个 Experiment 数据集；D=1、D=2；breadth=1。
- original_qbaf、jev_qbaf、jev_ew_qbaf 的根节点基础分为 0.5；两种 jev_prior 方法将 direct_jev 的根概率作为基础分。所有 QBAF 方法复用同一深度、同一样本的缓存图。
- D=2 在 D=1 图上继续生成，共有的第一层论点、基础分和边权均直接复用。
- API 模型额外接收与上游 Direct Prompting 一致的百分比格式要求，估计器、提示正文及解析规则保持原样。
- original_qbaf 的论点基础分来自上游 Direct Prompting 估计器；jev_qbaf 使用 Jev Noul 论点真确性概率；jev_ew_qbaf 进一步使用每条既有边的 Jev Noul 关系有效性概率。
- jev_prior_qbaf 使用 Jev 根先验、Jev 论点分数和单位边权；jev_prior_ew_qbaf 再使用已缓存的 Jev 关系边权。两者均复用 direct_jev 的根概率，没有新增根打分请求。
- EW-DF-QuAD 对每条边先计算 σ(父论点) × 边权，再使用原有乘积聚合及线性影响函数。
- Accuracy 以概率 > 0.5 为真；Brier 为平均平方误差；ECE 为 10 个等宽概率区间的平均置信度与正例率差的加权和。
- 生成模型按配置币种 CNY 计价，Jev 按美元计价；报告分别列示美元和人民币，不进行汇率换算。表中各 QBAF 方法都计入相同的共享论点生成成本，因此方法行的成本不可相加。两种 jev_prior 方法还计入同一条已缓存的根论点 Jev 请求。延迟是每样本顺序执行相应方法调用的平均耗时；缓存命中仍使用原始调用的记录耗时。

## 研究问题与结论

本实验检验：当 Jev 对根论点已有初始判断时，结构化支持与攻击证据能否通过 QBAF 改善这个判断。两条新方法都令根论点基础分等于同一样本的 `direct_jev` 概率，非根论点基础分等于已缓存的 Jev Noul 概率。`jev_prior_qbaf` 的所有既有边权为 1，使用标准 DF-QuAD；`jev_prior_ew_qbaf` 为每条既有边使用已缓存的 Jev 关系有效性概率，使用 EW-DF-QuAD。两者均不改变图或关系类型。

**本次设置下，结构化论证没有稳定改善强 Jev 先验。** 三个数据集、两个深度的六组全量比较中，两条新方法的 Accuracy 和 Brier 均劣于 `direct_jev`；ECE 也均升高。EW 边权在六组中都降低了相对于单位边权版本的 Brier，但仍未超过 `direct_jev`。这些是同一图、同一 Jev 根先验和同一批 Jev 论点分数上的配对结果。

根节点同时存在非 N/A 且 Jev 论点分数大于 0 的支持和攻击论点的子集共有：TruthfulClaim 236 条、StrategyClaim 244 条、MedClaim 267 条；同一数据集的 D=1 与 D=2 复用第一层，因此该子集数量相同。这个子集中个别配置有小幅改善，例如 MedClaim D=1 的 `jev_prior_qbaf` 相对 `direct_jev` 的 Accuracy 增加 0.0187、Brier 减少 0.0098；两项配对 95% 区间都跨过 0，不能据此认定稳定改善。

更直接的“先验反向证据”子集中，标准 DF-QuAD 在根分数为 0.5 时给出的方向与 Jev 根判断相反。每组有 63–100 条样本。在六组中，两条新方法的 Accuracy 均下降，Brier 均升高。例如 StrategyClaim D=2 的 100 条反向证据样本，`direct_jev` 的 Accuracy 为 0.700，`jev_prior_qbaf` 为 0.500：19 次纠错、40 次误改；边权版本为 0.550：17 次纠错、32 次误改。这里的“反向证据”由模型输出定义，没有使用真实标签筛选，因此可直接检验论证结构与初始判断冲突时的修正效果。

## 解释范围

- 上表的 API 成本和延迟是原始缓存记录中各方法所需调用的归属成本与调用耗时；这次离线重算没有产生新的 API 请求。去重后的总调用数和总成本与五方法原实验相同。各方法行共享图生成、Jev 根先验和其他可复用调用，不能把行成本相加。
- D=1 与 D=2 使用同一批根论点，因而两个深度的结果不是独立重复实验。配对区间为每个数据集、深度与子集分别计算的探索性区间，未做多重比较校正。
- 结果支持“本次 DeepSeek 生成论点、Jev 评价论点及关系、标准/加权 DF-QuAD 的组合未能可靠修正 Jev 先验”这一限定结论；不能推广为所有论证图或所有 QBAF 设计都无法修正先验。

完整数值和配对区间另存于 [指标 JSON](2026-09-26_jev_prior_qbaf_metrics.json)；逐样本结果位于本地 `experiment_results/prior_full/data/`。
